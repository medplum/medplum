# Viewing multiple Schedules in a single calendar UI

Pass an array of objects as the `sources` prop. You may specify the name of a
Mantine theme color to use for the slots of a source, and for the chips its
appointments carry, as its `color` attribute. You may also specify this on the Schedule included in a
source via a custom extension:

```
{
  "resourceType": "Schedule",
  "id": "my-schedule-uuid",
  "actor": [{ "reference": "Practitioner/my-practitioner-uuid" }],
  "extension": [
    {
      "url": "https://medplum.com/fhir/StructureDefinition/SchedulingColor",
      "valueString": "blue"
    }
  ]
}
```

 If the color value is not valid under the current Mantine theme, it is
 ignored. If no color is passed, an arbitrary color will be assigned.

# Appointments on several calendars

An appointment held on more than one of the schedules you pass is drawn once,
carrying a color-coded chip for each calendar it is on rather than a block per
calendar. A chip is named by its source's `label`, falling back to the name of
its Schedule's actor, cut down to what fits inside an appointment block; hovering
a chip names the calendar in full. Appointment blocks too short for a line of
text per chip show the chips as dots instead.

The schedule handed to `onSelectAppointment` and `onDoubleClickAppointment` is
that of the first source in `sources` that the appointment is on.

# Highlighting Availability

You may pass the `availableTime` prop to highlight recurring availability.
This takes the same shape as
[`HealthcareService.availableTime`](https://www.medplum.com/docs/api/fhir/resources/healthcareservice).
