## Usage

The [StructureDefinition](/docs/api/fhir/resources/structuredefinition) resource describes a structure - a set of data element definitions, and their associated rules of usage. These structure definitions are used to describe both the content defined in the FHIR specification itself - Resources, data types, the underlying infrastructural types, and also are used to describe how these structures are used in implementations. This allows the definitions of the structures to be shared and published through repositories of structure definitions, compared with each other, and used as the basis for code, report and UI generation.

Note that as part of the specification itself, a [full set of structure definitions](https://www.hl7.org/fhir/downloads.html#profiles) for all resources and data types is published.

## Relationships

- StructureDefinitions are used by [CapabilityStatement](/docs/api/fhir/resources/capabilitystatement) instances for specifying how resources are used
- StructureDefinitions use [Value Sets](/docs/api/fhir/resources/valueset) to specify the content of coded elements

## Background and Context

Implementers should be familiar with the background and concepts described in [Profiling FHIR](https://www.hl7.org/fhir/profiling.html) before working with this resource.

#### Metadata[](/docs/api/fhir/resources/structuredefinition 'link to here')

The [StructureDefinition](/docs/api/fhir/resources/structuredefinition) resource has a set of metadata that is mostly shared with the [Value Set](/docs/api/fhir/resources/valueset), [CapabilityStatement](/docs/api/fhir/resources/capabilitystatement) and other infrastructure resources. The metadata describes the structure and helps find the structure when registered in repositories.

Notes:

- The name and title of the structure are not required to be globally unique, but the name amd title should have some scoping information (e.g. AcmeAllergies / Acme Inc. (USA), Allergy [List](/docs/api/fhir/resources/list))
- Multiple keywords may be assigned to the structure. These may either describe the structure, the focus of the structure or both. They are solely to help find the structure by searching for structured concepts
- The 3 status codes (draft, active, and retired) are the codes that are relevant to structure consumers. Authors may wish to use the [authoring-status](https://www.hl7.org/fhir/#author-status) extension to track the life cycle of a structure as it is prepared
