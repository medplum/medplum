## Usage

This resource is a non-persisted resource used to pass information into and back from an [operation](https://www.hl7.org/fhir/operations.html).

## Relationships

This special resource has no other use than for operation parameters, and there is no RESTful end-point associated with it. For further information, see the [operations](https://www.hl7.org/fhir/operations.html) page.

[OperationDefinition](/docs/api/fhir/resources/operationdefinition) defines constraints on the [Parameters](/docs/api/fhir/resources/parameters) resource instances that are used to convey the inputs and outputs of the operation.
