## Usage

A potential negative outcome from the use of a medicinal product. This is part of the definional information about a product and is not realted to any particular actual use of a medication. See also [AdverseEvent](/docs/api/fhir/resources/adverseevent), which is for actual events (or near misses), and [AllergyIntolerance](/docs/api/fhir/resources/allergyintolerance).
