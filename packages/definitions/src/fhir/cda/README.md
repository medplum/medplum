# CDA logical model

`hl7.cda.uv.core-2.0.0-sd.json` is the HL7 CDA R2 logical model (FHIR StructureDefinitions), from
https://hl7.org/cda/stds/core/2.0.0-sd/package.tgz, licensed CC0-1.0. Narrative `text` was stripped.

The generator (`npm run ccdatypes` in `packages/generator`) reads it to produce the `@medplum/ccda` types.
